# Bolajonlar — ta'limiy ilova

Bu papka bolalar uchun Uzbek tilidagi interaktiv ta'lim ilovasining tayyor web/PWA prototipidir.

## Bo'limlar
- O'zbek alifbosi
- 1–10 sonlar
- Ranglar
- Geometrik shakllar
- Tana a'zolari
- Vaqt / soat
- Hayvonlar
- Mevalar
- Quiz

## Ishga tushirish
`index.html` faylini brauzerda oching.

GitHub Pages uchun:
1. Fayllarni GitHub repository'ga yuklang.
2. Settings → Pages → Deploy from branch ni tanlang.
3. `main` branch va `/root` papkasini tanlang.
4. Sayt havolasi hosil bo'ladi.

Eslatma: SVG ikonlar ilova ichida ishlashi uchun `assets/icons` papkasini ham birga yuklash kerak.
